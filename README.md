# News Daily — context repo

Nguồn dữ liệu cho cloud routine "News Daily" (Claude Code Scheduled Routine): đọc `sources.md` và `interests.md` mỗi sáng 7h (giờ VN) để tổng hợp và gửi email digest tin tức.

- `sources.md` — danh sách trang báo ưu tiên quét
- `interests.md` — chủ đề quan tâm, dùng để lọc/tìm thêm tin ngoài danh sách nguồn

`Raw Data/` (Obsidian clippings gốc) không đưa vào repo này — chỉ dùng local để tham khảo khi cập nhật 2 file trên.
